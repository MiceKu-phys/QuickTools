## 快速开始

### 本地打开

直接双击任一 `.html` 文件，在浏览器中离线使用；或将整个目录拷贝到手机 / 平板，用浏览器打开。

### 远程打开（GitHub Pages）


```
https://MiceKu-phys.github.io/quicktools/
```

入口页 `index.html` 提供封面与目录（SPA 原地切换，规划中）。
